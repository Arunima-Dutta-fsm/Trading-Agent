# Experiment log

The brief asks the group to "keep a record why an experiment failed or succeeded". Add one entry each
time you change the LLM, an indicator, a threshold or a risk limit. The matching reports are in
`model-run/` (search by date) and the old settings are in `configs/history/`.

| Date (IST) | Who | What changed | Why | Runs / reports compared | Result | Keep? |
|---|---|---|---|---|---|---|
| | | | | | | |

Things worth comparing: number of BUY setups found per run, how many were blocked and by which check,
how often the agent needed the safety net (per LLM), backtest return / drawdown / Sharpe against
buy-and-hold and SPY, and paper P&L against SPY over the same days.
